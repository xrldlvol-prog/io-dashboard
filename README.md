# 한국 산업구조 진단·시뮬레이션 대시보드

2023년 투입산출표(생산자가격)를 이용해 산업 간 연관 구조를 진단하고, 수요 증가와 공급 충격의 파급효과를 계산하는 웹앱입니다. 별도 서버 없이 브라우저에서 계산합니다.

- **웹앱 주소:** https://xrldlvol-prog.github.io/io-dashboard/
- **저장소:** https://github.com/xrldlvol-prog/io-dashboard

## 1. 사용 자료와 출처
- 자료: 한국은행 산업연관표 2023년 연장표, 생산자가격 기준 (수업에서 제공받은 엑셀 4종)
- 분류 수준: 대분류 33개, 중분류 83개, 소분류 165개, 기본부문 380개
- 개인정보는 포함되어 있지 않으며, 산업 단위로 집계된 통계입니다.
- 원자료(엑셀)를 `build_data.py`로 JSON(`large.json`, `mid.json`, `small.json`, `basic.json`)으로 변환해 사용합니다.

엑셀 12개 시트는 모두 **① 원자료 탐색** 탭에서 열람할 수 있습니다(거래표 3, 투입계수표 3, 유발계수표 3, 최종수요 항목별 유발액 3). 이 중 분석 탭(②~④)에서 계산에 쓰는 시트는 다음과 같습니다.

| 시트 | 사용 내용 |
|---|---|
| 총거래표(생산자) | 산업 간 거래액, 총산출, 소비·투자·수출, 수입, 부가가치 구성 |
| 생산유발계수 | 영향력·감응도계수, 시나리오의 생산유발액 계산 |
| 수입유발계수 | 시나리오의 수입유발액 (열합) |
| 부가가치유발계수 | 시나리오의 부가가치유발액 (열합) |
| 수입투입계수 | 수입 중간재 의존도 순위 |

## 2. 단위
- 금액: 원자료는 **백만원**입니다. 화면에는 억원(1억원 = 100백만원)과 조원(1조원 = 1,000,000백만원)으로 환산해 표시합니다.
- 시나리오 입력 금액: **억원**, 국산품에 대한 최종수요 증가액
- 영향력계수·감응도계수: 평균을 1로 맞춘 **상대지수**(단위 없음)
- 생산·수입·부가가치유발계수: 최종수요 1원 증가당 유발되는 금액(원/원, 단위 없음)
- 수출·소비·투자 비중: 최종수요(수출+소비+투자) 중 각 항목의 비율(%)

## 3. 사용법
**먼저** 화면 오른쪽 위 **분류 수준**(대/중/소/기본부문)을 고르고 **"불러오기" 버튼**을 누릅니다. 투입산출표가 로딩되면("○개 부문 로딩 완료" 표시) 아래 ①~④ 탭을 사용할 수 있습니다. 로딩 전에는 안내 상자만 보입니다. 분류 수준을 바꾸면 해당 표가 다시 로딩됩니다.

1. **① 원자료 탐색:** 엑셀 12개 시트(거래표 3, 투입계수표 3, 유발계수표 3, 최종수요 항목별 유발액 3) 중 하나를 고르고 "불러오기"를 누르면 해당 시트가 로딩됩니다. 행(산업)을 이름이나 코드로 검색해 선택하면 열 코드, 열 이름, 원자료 값이 표로 나오고, 열도 검색할 수 있습니다. 금액표는 백만원, 계수표는 단위 없는 비율이며 시트별 단위가 로딩 후 화면에 표시됩니다.
2. **② 산업 진단:** 영향력(x)·감응도(y) 산점도에서 점을 클릭하거나 목록에서 산업을 선택하면 유형, 주요 공급처·수요처 Top 10, 비용 구조가 표시됩니다.
3. **③ 파급효과 시뮬레이터:** 시나리오 A 또는 B를 고르고 산업과 증가액(억원)을 입력한 뒤 "추가"를 누릅니다. 여러 산업을 추가하면 합산되며, 두 시나리오의 생산·부가가치·수입 유발액과 상위 10개 산업을 비교합니다.
4. **④ 수출·수입 구조와 공급충격:** 선택한 지표의 상위 15개 산업을 막대그래프로 보고, 산업과 감소율을 입력해 "계산"을 누르면 하류 산업의 생산 감소 상위 10개를 표시합니다.

## 4. 분석 방법
- **영향력계수** = 해당 산업 생산유발계수 열합 ÷ 전 산업 열합의 평균. 1보다 크면 다른 산업을 끌어올리는 힘이 평균 이상입니다.
- **감응도계수** = 해당 산업 생산유발계수 행합 ÷ 전 산업 행합의 평균. 1보다 크면 다른 산업의 수요 증가에 평균 이상으로 영향을 받습니다.
- **수요 증가 시뮬레이션:** 생산유발액 = 생산유발계수 행렬 × 최종수요 증가액. 부가가치·수입 유발액은 부가가치유발계수·수입유발계수의 열합에 증가액을 곱해 더합니다.
- **공급충격(고쉬 공급측 모형, 단순 추정):** 선택한 산업의 생산이 줄면 판매 비중(거래액 ÷ 해당 산업 총산출)에 따라 하류 산업으로 충격이 전파되는 것을 30회 반복 계산해 누적합니다.

## 5. 한계
- 가격 변화, 대체재, 재고 조정, 설비 용량 제약은 반영하지 않습니다.
- 시뮬레이션은 국산품에 대한 최종수요 증가만 다루며, 투자 지출과 최종수요는 구분해 입력해야 합니다.
- 공급충격은 전파 효과를 크게 잡는 단순 모형이므로 상한에 가까운 값으로 해석해야 합니다.
- 고용·지역 분석은 자료에 없어 다루지 않습니다.

## 6. 파일 구성
- `index.html`: 화면과 계산 코드
- `large.json`, `mid.json`, `small.json`, `basic.json`: 분석 탭(②~④)용 변환 자료
- `s_<분류>_<01~12>.json`: ① 탭이 시트별로 불러오는 원자료 (분류 4개 × 시트 12개 = 48개)
- `build_data.py`, `build_sheets.py`: 엑셀을 JSON으로 변환하는 스크립트
